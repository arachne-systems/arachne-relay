# Security

Do not report vulnerabilities in public issues.

- For a vulnerability in the upstream Iroh relay binary, use the upstream
  [private vulnerability reporting form](https://github.com/n0-computer/iroh/security/advisories/new).
- For a vulnerability in this repository's Docker recipe or deployment
  instructions, use GitHub's private vulnerability reporting for this repo.

After this repository is public, maintainers should enable GitHub's private
vulnerability reporting and verify that the report form is available.
